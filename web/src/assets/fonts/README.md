# Bundled fonts

These files are the latin variable-font subsets served by Google Fonts for the
families the settings screen offers. They are bundled so the IDE never makes a
network request for typography (Task 8: strict CSP, offline-first).

| File | Family | Source |
|---|---|---|
| `fira-code.woff2` | Fira Code | https://fonts.google.com/specimen/Fira+Code |
| `jetbrains-mono.woff2` | JetBrains Mono | https://fonts.google.com/specimen/JetBrains+Mono |
| `roboto-mono.woff2` | Roboto Mono | https://fonts.google.com/specimen/Roboto+Mono |
| `source-code-pro.woff2` | Source Code Pro | https://fonts.google.com/specimen/Source+Code+Pro |

All four families are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org). The files are unmodified subsets generated by
