Marker anomaly (recorded, not reproducible)
-------------------------------------------
The unattended first launch at 14:49 wrote
`localStorage["leocode.onboarding.v1"]="1"` by 14:50 with no input sent by this
harness, so the first captured screen after reconnecting was the IDE. To test
the first-run path the app data was cleared (`pm clear dev.leocode`); onboarding
then showed and every row above passed. A second `pm clear` + launch was left
untouched for 25 s: the marker stayed `null` and the onboarding was still open
(`Welcome to LeoCode`, step 1 visible), so no auto-finish path was found. The
14:50 write is treated as a stray touch on the unattended screen; the clean
first-run behaviour is the one recorded here.
