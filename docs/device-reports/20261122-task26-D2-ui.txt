Defect found and fixed
----------------------
The first Run after opening the project failed with:
  /data/user/0/dev.leocode/files/workspaces/209e19e0/.venv/bin/python: can't
  open file '/data/user/0/dev.leocode/files/workspaces/default/demo.py':
  [Errno 2] No such file or directory
`ProcHandler` resolved a relative `cwd` against `workspace.defaultWorkspace`
instead of the active workspace. It now takes an `activeRoot` supplier (wired to
`WorkspaceStore.activeDirectory()`), matching the trust/python handlers.
`ProcHandlerTest.relative cwd uses the active workspace` covers it.
