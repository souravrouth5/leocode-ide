Network note
------------
The LAN has no direct internet. The host ran a small forwarding proxy on
127.0.0.1:18080 to the authenticated upstream proxy, exposed to the device with
`adb reverse tcp:18080 tcp:18080`. For the UI demo, a local wheelhouse was served
on 127.0.0.1:18081 and exposed with `adb reverse tcp:18081 tcp:18081`, so pip
installed from a deterministic local index. This is test plumbing only; the
production path (PyPI through the device's network) is covered by T15 and the
earlier compatibility probes.

App UI — full flow
------------------
The D1 app workspace is the default scratch project. `demo.py` and
`requirements.txt` were written with `run-as`; no real project was touched.

1. Runtimes → "This project's Python" shows the runtime path, `not created`
   environment, `not installed` requirements, and `python, pip` aliases.
   Screenshot: 20261122-task26-d1-panel.png
2. "Create environment" → trust sheet ("A project environment runs Python from
   the bundled runtime in this project."). Accepted.
   Screenshot: 20261122-task26-d1-trust.png
3. Environment becomes `<workspace>/.venv/bin/python`.
   Screenshot: 20261122-task26-d1-venv.png
4. "Install requirements" → pip trust sheet. Accepted; pip log streamed into the
   panel and ended with all six packages installed
   (certifi, charset-normalizer, idna, markupsafe, requests, urllib3).
   Screenshot: 20261122-task26-d1-pip-log.png
5. Run `demo.py` → script trust sheet. Accepted; output:
     hello from /data/data/dev.leocode/files/workspaces/default/.venv/bin/python
     python 3.14.10
     requests 2.34.2
     markupsafe &lt;b&gt;
   EXIT 0. Screenshot: 20261122-task26-d1-run.png
6. Run again → no prompt; the grant persisted for the unchanged script.
   Screenshot: 20261122-task26-d1-run-again.png (same output, no sheet)
7. Edit `requirements.txt` on disk (add `# changed`), then Run → "Install
   requirements?" sheet.
   Screenshot: 20261122-task26-d1-requirements-prompt.png
   "Install and run" → the pip trust sheet reappeared because the requirements
   fingerprint changed; accepted, pip reinstalled, script ran, EXIT 0.
   Screenshot: 20261122-task26-d1-install-run.png

Result: PASS for the D1 UI flow, including trust persistence and
requirements-driven re-prompting.
