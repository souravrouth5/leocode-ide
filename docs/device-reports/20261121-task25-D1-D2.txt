Notes
════════════════════════════════════════════════════════════════════

- The download retries up to three times with a `Range` request and a 2 s
  delay. A checksum/size violation is not retried; it fails with E_INTEGRITY.
- E_OFFLINE leaves the partial file in `cache/runtime-download/`; a later
  `runtime.install`/`runtime.repair` resumes from that byte count.
- E_CANCELLED removes `usr.staging` and leaves the installed tree and its
  marker untouched.
- D1's resume demo was not repeated because D1 is reachable only over Wi-Fi
  ADB; turning the radio off would drop the test transport. D2 covers the
  resume path end to end over USB ADB.
- D2's first fresh install took 497 s and the resumed install 333 s; D1's
  first install took 74 s on a faster link.
