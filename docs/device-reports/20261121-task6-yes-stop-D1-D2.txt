============================================================
Fix found by this demo
============================================================
Before the fix, Stop all killed the PTYs but an attached page kept showing
"pty" for a shell that no longer existed (writes were silently dropped).

TerminalRegistry now reports the stop to the attached listener:

  companion object { const val EXIT_STOPPED = 143 }
  closeAll() -> session.close(notifyExit = true)
  Session.close(notifyExit) delivers Listener.exit(EXIT_STOPPED) before
  pty.destroy() (which sends SIGTERM, then SIGKILL after the grace period).

143 is SIGTERM, the first signal destroy() sends. `term.close` (the page
disposing its own session) still closes silently, as before.

Unit test: TerminalRegistryTest."closeAll reports an exit to an attached
listener" (exit code 143, activeCount 0).
