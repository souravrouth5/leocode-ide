## Summary
- R-04: Implemented real root pid tracking and graceful SIGTERM -> 200 ms liveness polling -> SIGKILL termination in `ProcessSupervisor` and `PtySession`. `ProcessSupervisor` runs `[suPath, "-c", RootManager.buildRootCommand(...)]`, resolves root pid off-thread via `rootManager.awaitRootPid`, and kills real root pid on cancel without calling `NativePty.killGroup` or relying on client `waitFor`. `PtySession` builds `exec <su> -c '<RootManager.buildRootShell(pidFile)>'` with real root pid destruction and liveness polling via callbacks.
- R-03 + R-07: Implemented root refusal vs failure classification in `ProcessSupervisor` and `TerminalRegistry`. When pidfile never appears and exit code is non-zero, classifies as denied only if nothing was output to stdout, invoking `rootManager.markLost()` and emitting `root.lost` (`reason="denied"`) before `proc.exit` / `term.exit`. When pidfile appears, calls `rootManager.markGranted()`. Updated `ProcHandler` and `TermHandler` to validate `!isAvailable()` -> `E_ROOT_UNAVAILABLE` and `!canUseRoot()` -> `E_ROOT_DENIED`.
- R-05: Added `TerminalRegistry.closeRoot()` and `ProcessSupervisor.cancelRoot()` to terminate only active root sessions and jobs when root is disabled, wired in `AppGraph` to locked `RootHandler` constructor.
- R-06: Updated `OrphanReaper.reap()` to skip `root-proc` and `root-term` records, preserving their files. Implemented `RootOrphanReaper` to lazily reap root orphan pidfiles via `parseRootPidFile`, liveness check, TERM -> 200ms -> KILL only when `canUseRoot()`, deleting pidfiles in all cases. Wired lazy execution in `AppGraph` before first root job/session and upon successful root enable/grant.
- Updated `AppGraph.diagnostics()` wording: "root mode enabled (granted)", "root mode enabled (not verified this session)", "su binary present (not enabled)", else "not detected".

## Tests added
- `ProcessSupervisorTest`:
  - `root cancel kills the recorded root pid and never calls client kill when pid is known`: Proves root process cancellation targets the real root pid recorded in the root pidfile and not the client wrapper pid.
  - `root job whose pidfile never appears and exits non-zero emits root lost before exit and marks lost`: Proves root refusal emits `root.lost` before `proc.exit`, sets `reason="denied"`, and invokes `markLost()`.
  - `pidfile that appears marks root granted`: Proves appearing root pidfile calls `markGranted()`.
  - `cancelRoot leaves non-root jobs running`: Proves `cancelRoot()` terminates only root jobs while leaving active non-root jobs undisturbed.
  - `missing pidfile with stdout output is normal failed run without root lost`: Proves exit code non-zero with stdout output is treated as normal failure without emitting `root.lost` or marking lost.
- `TerminalRegistryTest`:
  - `closeRoot closes only root sessions`: Proves `closeRoot()` stops only sessions with `root = true` through their root kill path while non-root sessions remain active.
  - `root sessions record kind root-term in pid file store`: Proves root terminal sessions record `root-term` kind in registry listings and pidfile store.
  - `root terminal refusal emits root lost before exit and marks lost`: Proves terminal refusal emits `root.lost` event before `term.exit` and marks root lost.
- `OrphanReaperTest`:
  - `root kinds are skipped and their files kept`: Proves `OrphanReaper.reap()` skips `root-proc` and `root-term` files and leaves them untouched while reaping normal `proc` orphans.
- `RootOrphanReaperTest`:
  - `canUseRoot false does not make shell calls and keeps files`: Proves reaper makes zero shell calls and retains files when `canUseRoot()` is false.
  - `stale start time does not kill and deletes file`: Proves process with mismatched start time is not signalled and stale file is deleted.
  - `alive and matching process is killed with TERM then KILL and deletes file`: Proves active matching orphan is signalled with TERM, waited 200 ms, then KILL, and pidfile deleted.
  - `unparseable file is deleted with no kill`: Proves corrupt or invalid pidfile is cleanly deleted without signalling.
- `ProcHandlerTest`:
  - `root run returns E_ROOT_UNAVAILABLE when root is not available`: Proves missing su binary throws `E_ROOT_UNAVAILABLE`.
  - `root run returns E_ROOT_DENIED when canUseRoot is false`: Proves su available but disabled/unverified throws `E_ROOT_DENIED`.
- `TermHandlerTest`:
  - `root open returns E_ROOT_UNAVAILABLE when root is not available`: Proves missing su binary throws `E_ROOT_UNAVAILABLE`.
  - `root open returns E_ROOT_DENIED when canUseRoot is false`: Proves disabled/unverified root mode throws `E_ROOT_DENIED`.
