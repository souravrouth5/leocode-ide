# B1 report

## Summary
- Implemented enforced timeouts in `ProcessShellRunner` with child stdin closure, stdout and stderr bounded draining (capped to 64 KiB each) on daemon threads, and forced destruction with bounded reader joins on timeout.
- Added `@Volatile private var grantCache: Boolean?` to `RootManager`, ensuring `status()` and `isGranted()` make zero shell calls across all states.
- Handled `requestGrant()` timeouts and denials with grant cache updates, `markGranted()`, `markLost()`, and cache reset on `setEnabled(false)`.
- Added `/debug_ramdisk/su` and `/system_ext/bin/su` to `DEFAULT_SU_PATHS` with explanatory comments on omitting `/data/adb/...`.
- Added companion root-pid helpers `buildRootCommand`, `buildRootShell`, `parseRootPidFile`, `RootPid`, and instance polling/liveness helpers `awaitRootPid` and `isRootPidAlive`.

## Tests added
- `ProcessShellRunner timeout destroys process forcibly and returns timeout result`: Proves that a process whose stdout never reaches EOF triggers `destroyForcibly()`, joins reader threads, and returns within 1.5 s with exit -1 and the timeout message.
- `ProcessShellRunner caps output to 64 KiB without blocking full pipe`: Proves that a child writing 1 MiB to stderr drains without pipe deadlock, caps captured output to 64 KiB, and preserves exit code 42.
- `ProcessShellRunner start throws returns exit minus one and does not escape`: Proves exceptions during process launch are safely caught and return `ShellResult(-1, "", message)`.
- `status and isGranted make zero shell calls and use grant cache`: Proves status checks and `isGranted()` do not invoke `su` in any state, and cached grant status reflects successful grant.
- `requestGrant timeout or denial updates cache and canUseRoot`: Proves request timeouts and denials throw `E_ROOT_DENIED`, invalidate `grantCache`, and toggle `canUseRoot()`, while `markLost()` and `setEnabled(false)` manage cache lifecycle.
- `default su paths include debug_ramdisk and system_ext but not data adb`: Proves `DEFAULT_SU_PATHS` contains `/debug_ramdisk/su` and `/system_ext/bin/su`, excluding `/data/adb`.
- `buildRootCommand and buildRootShell construct expected commands with quoting`: Proves exact POSIX single-quote escaping for cwd, pidFile, and special arguments (`$`, backticks, spaces, single quotes, semicolons).
- `parseRootPidFile parses valid text and rejects invalid`: Proves parsing `<pid> <starttime>` format and strict rejection of empty, non-numeric, pid <= 1, and malformed strings.
- `awaitRootPid returns when file appears and null on timeout`: Proves non-su polling for root pidfile appearance and bounded null return on timeout.
- `isRootPidAlive verifies process existence and start time matching`: Proves verification of root process liveness via `kill -0` and matching `/proc/<pid>/stat` starttime ticks.
