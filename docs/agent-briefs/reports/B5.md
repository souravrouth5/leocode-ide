- `web/src/features/root/phantom.test.ts`:
  - `returns true when SDK >= 31, root is enabled, and root is not lost`: verifies visibility when SDK is 31, 34, 35.
  - `returns false when SDK < 31`: verifies option is hidden on SDK 30, 28, 0.
  - `returns false when SDK is unknown, null, or undefined`: verifies option is hidden when SDK is unavailable or NaN.
  - `returns false when root is disabled`: verifies option is hidden when root mode is off.
  - `returns false when root is in a lost state`: verifies option is hidden after a revocation event.
  - `returns false when disabled and lost`: verifies option is hidden when both off and lost.
  - `matches the exact command argv and timeout`: verifies exact argv array and 15000 ms timeout.
  - `returns androidSdk from bridge.info()`: verifies SDK is parsed from `app.info`.
  - `falls back to diagnostics when bridge.info() has no androidSdk`: verifies fallback to diagnostic report regex.
  - `returns null if info fails and diagnostics does not contain SDK`: verifies null when neither source has SDK.
  - `executes the command with root: true, timeoutMs: 15000 and returns stdout value`: verifies invocation via `bridge.run` with `root: true`.
  - `throws an error when bridge.run returns non-zero exit code`: verifies command error propagation.
- `web/src/components/SettingsDialog.test.tsx`:
  - `hides the phantom option button when root is disabled`: verifies UI button is not rendered when disabled.
  - `hides the phantom option button when SDK < 31`: verifies UI button is not rendered on Android < 12.
  - `hides the phantom option button when SDK is unknown/null`: verifies UI button is not rendered when SDK is missing.
  - `hides the phantom option button when root is in a lost state`: verifies UI button is not rendered when root was lost.

  - `tapping Apply until reboot opens confirm dialog; Cancel sends nothing`: verifies confirmation dialog open/close lifecycle and zero command invocation on Cancel.
  - `tapping Apply sends exactly the argv with root: true and displays read-back value`: verifies command execution with `root: true` and UI update showing read-back value.
  - `routes error to onApplyPhantomError when command fails`: verifies error routing on command failure.
